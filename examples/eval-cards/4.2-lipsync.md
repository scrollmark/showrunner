## LLM Evaluation Target

Audio matching verification: the dancer's mouthing will NOT match the spoken 'trending sound'. A correct analysis DETECTS the mismatch.

## Expected detections (grading checklist)

- [ ] Analysis recognizes the lip-sync/dance trend format
- [ ] PASS = the analysis flags imperfect/absent lip-audio sync
- [ ] FAIL = the analysis claims the lips match the track

## Notes

Generated video cannot sync lips to a specific track - so this example inverts the grading: mismatch detection is the pass condition.
